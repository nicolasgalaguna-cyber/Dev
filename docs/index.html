INICIA TU ESTUDIOPYTHON 3.11+ / O DOCKER
git clone https://github.com/nicolasgalaguna-cyber/Dev.git radiocomun
cd radiocomun
python3 scripts/seed_demo.py
export RADIO_TOKEN="tu-clave-segura-de-al-menos-16-caracteres"
python3 -m server.app

Abre http://localhost:8080 · La demo contiene tonos sintéticos originales, sin canciones comerciales.

02 / TRANSPARENCIA DESDE EL PRIMER DÍA

Una base real.
Un camino abierto.

IMPLEMENTADO

Estudio y automatización

Audio PCM mono a 22.05 kHz, mezcla de dos decks, preescucha, listas, programación, jingles, historial y acceso con clave compartida.

Micrófono con AudioWorklet y concesión temporal. Guiones locales y revisión editorial persistente.

REQUIERE CONFIGURACIÓN

Investigación y streaming

La investigación usa tu clave de OpenAI y búsqueda web. Sus resultados son borradores; una cita no garantiza que una afirmación sea cierta.

Docker incluye FFmpeg, Icecast y puente MP3. Este entorno de entrega no dispone de Docker ni FFmpeg para validarlos en ejecución.

HOJA DE RUTA

Producción a otra escala

Roles por usuario, WebRTC de baja latencia, estéreo a 48 kHz, normalización EBU R128, editor de ondas, reglas de no repetición y alta disponibilidad.

Las ondas de la consola son decorativas. El medidor master sí usa el nivel de salida real.

Esta página es compatible con GitHub Pages. La consola, el audio y la IA se ejecutan en tu servidor; GitHub Pages aloja archivos estáticos.
