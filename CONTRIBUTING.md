# Contribuir a RadioComún

Abre un issue con el problema, el resultado esperado y pasos para reproducirlo.
Para cambios en audio, describe también el formato, navegador y sistema operativo.

1. Crea una rama desde main.
2. Ejecuta `python -m unittest discover -s tests -v` y `node --check public/app.js`.
3. Usa solo audio original, CC0 o con permiso explícito en fixtures.
4. Conserva la separación entre investigación IA, fuentes, revisión e interpretación.
5. Documenta si un comportamiento es operativo, experimental o pendiente.

Los cambios de seguridad se comunican siguiendo SECURITY.md. No publiques claves ni datos de la emisora en issues.
